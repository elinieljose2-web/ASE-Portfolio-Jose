# Course Introduction

CPELX230-330 introduces the principles of modern software engineering with a
focus on agentic software engineering: building software that uses AI agents
capable of planning, deciding, and acting toward goals.

The course covers software processes, Agile and Scrum, version control with Git,
intelligent agents, and responsible AI practices guided by the NIST AI Risk
Management Framework.

As a computer engineering student, I expect to learn how to work in teams,
manage code with Git, and design AI-powered systems that are safe, secure,
and ethical. These skills are increasingly important because AI agents are
becoming part of everyday software development and engineering work.
